PLRA Bulk PDF Downloader v2 - Install & Use (Roman Urdu)
==========================================================

Yeh version pehle wale se alag hai: ab yeh har row ka "پرنٹ کریں" button
KHUD click karta hai (kyunke us site pe PDF ka link sirf click karne par
banta hai), aur jo bhi PDF/report tab khulta hai use pakad kar automatically
download kar leta hai.

INSTALL (ek dafa):
1. Zip extract karo (right-click > Extract All).
2. Chrome mai jao: chrome://extensions
3. "Developer mode" ON karo (top-right).
4. "Load unpacked" > extracted folder "plra-bulk-pdf-downloader" select karo.
5. Agar pehla version pehle se installed hai to usay chrome://extensions
   se "Remove" kar do, phir yeh naya wala "Load unpacked" karo.
6. Toolbar pe puzzle icon se PIN kar lo.

USE:
1. eregistration.punjab-zameen.gov.pk pe login karo.
2. Registry table wale page pe jao (jahan "پرنٹ کریں" icons har row mai hain).
3. Extension icon click karo.
4. "Scan Page" dabao - batayega kitni rows is page pe mili.
5. "Bulk Print & Download" dabao - extension khud har row ka print button
   click karega (thori delay ke sath), jo tab khulega usay pakad kar PDF
   download kar lega aur tab band kar dega. Status "Downloaded k/N..." dikhega.
6. Chrome download popup mehfooz rakho (ya "Allow multiple downloads" ki
   permission de do agar Chrome puchay).
7. Agle page pe jao (pagination), dobara Scan > Bulk Print & Download.

NOTES / TROUBLESHOOTING:
- Jab tak yeh chal raha hai, tab band mat karo.
- Agar Chrome "This site is trying to open several tabs" dikhaye, "Allow"
  pe click kar do (ek dafa) taake baqi downloads bhi chal sakein.
- Filenames: plra_pdf_1_<processId>.pdf, plra_pdf_2_<processId>.pdf, waghera.
- Issue aye to screenshot bhej dena.
