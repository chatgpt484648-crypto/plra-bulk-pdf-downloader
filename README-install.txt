PLRA Bulk PDF Downloader - Install & Use (Roman Urdu)
=====================================================

INSTALL (ek dafa):
1. Yeh zip download karo aur RIGHT-CLICK > Extract All se kahin bhi extract karo
   (jaise Desktop pe folder "plra-bulk-pdf-downloader").
2. Chrome mai jao: type karo  chrome://extensions  aur Enter.
3. Top-right pe "Developer mode" ON karo.
4. "Load unpacked" pe click karo aur extracted folder "plra-bulk-pdf-downloader" select karo.
5. Extension install ho jayega. Toolbar pe puzzle icon se usko PIN kar lena.

USE (PLRA registry PDFs bulk download):
1. Login karo https://eregistration.punjab-zameen.gov.pk/ pe.
2. Us page pe jao jahan registry rows ka table hai (jahan print icons hain).
3. Extension ka icon click karo (toolbar se).
4. "Scan Page" dabao - extension us page ke saare print/report links
   (ReportViewer.aspx wale) ikatthe kar ke list dikha degi.
5. "Download Selected" dabao - saari PDFs ek ke baad ek auto download
   hongi ( filenames plra_pdf_1_..., plra_pdf_2_... ), tumhe kuch nahi
   karna.
6. Agar PDFs seedha download na hon (site viewer page kholti hai), to
   "Open in Tabs" dabao - har link background tab mai khul jayega aur
   site khud PDF download karegi.

NOTES:
- Har page scan usi page ke links deta hai. Table 20 rows per page hai,
  to har page pe jao, Scan > Download karo.
- Scan ke baad jo link nahi chahiye, uska checkbox untick kar do.
- Manual koi URL add karna ho to neeche box mai paste karo aur "Add" dabao.
- Remove karne ke liye: chrome://extensions pe extension card pe "Remove".
